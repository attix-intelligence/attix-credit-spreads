Cross-fleet findings

  • The fill model flattered everything but was never the problem. Removing unfillable entries shrinks losses where sizing was protected (EXP-800 −49→−33%) and worsens them where it wasn't (EXP-400 −61→−74.5%; EXP-V8A −9.5→−22%). No sign flips anywhere; per-trade quality is uniformly worse under marketable (win rates −3…−7 pp).
  • All four ruins are the champion 17%-flat-sizing family. The 2026 paper quarter's +0.2%…+25% results for the same configs were rally beta, full stop.
  • The differentiators don't differentiate. 3303B's regime gate fired 0 times in 41k evaluations; 3311's NFP gate (which dodged the one live killer trade) doesn't rescue a 17%-sized core over six years; 401/503 overlays have no engine support and never traded live. Only EXP-1220's sizing/stop discipline changes outcomes (−5.9% vs −100%s).
  • Twin debt is fleet-wide. Zero fully faithful twins; three explicit no-twin verdicts (401, 503, V8A portfolio); registry backtest_expectations for 3303B/3309/3311 are provenance-invalid.
  • Go-live consequence: the edge gate is not met by any strategy in the program — including top candidate EXP-1220 (≈ break-even). Measurement is now honest (FIX #1–4); the measured edge at deployed parameters is ≤ 0 everywhere. Next work must change the strategies, not the instruments.
Method note. “Naive” = legacy instant fill at scan-bar close minus slippage. “Marketable” = limit at decision-time open spread mark minus slippage; fills only if traded through by bar close, else fill-or-cancel (per-slot fresh limits = live FIX #2 reprice ladder; pre-9:30 slots place no order). All naive re-runs reproduced the recorded Jul-3 baselines exactly — FIX #3 left the legacy path untouched, so marketable deltas are attributable to the fill model alone.
