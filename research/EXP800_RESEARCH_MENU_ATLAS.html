1 · How to run honestly — mandatory

Every backtest below is meaningless unless run with the honest fill model.
  • backtest.fill_model: "marketable" (FIX #3). Runner: python experiments/EXP-800-BT-safe-kelly/run.py <variant> marketable — extend this for sweeps.
  • Verify results JSON: fill_model == "marketable" and fill_model_naive_fallbacks ≈ 0 (investigate if > 2% of entries).
  • No pre-09:30 entries; slippage model ON; all pricing from IronVault (any synthetic-credit path = critical bug, abort).
Overfitting guardrails (pre-registered success bar). Train 2020-01 → 2023-12, test 2024-01 → 2026-04; one look at test per candidate. A cell "wins" only if, in train AND test: return > 0 and Sharpe ≥ 0.5; ≥ 150 honest fills full-period; plateau not spike (adjacent cells also ≥ 0 — an 80-cell grid produces ~4 false positives by chance); survives an extra −$0.05 slippage stress. Always report fill-rate — a "profitable" cell filling 4% of signals is a different, fragile strategy.

3 · The experiments

Axis A — Structure

RM-A1 · Coarse structure grid P0 · Effort M

Hypothesis Negative honest edge is specific to short-DTE, near-money, mid-width spreads; longer DTE / further OTM has a better credit-to-spread-cost ratio.
Sweep target_dte ∈ {7, 15, 30, 45} × otm_pct ∈ {1%, 2%, 3%, 5%} × spread_width ∈ {$5, $10, $12, $15, $20} = 80 cells; all else at baseline.
Success Any cell passing the Section-1 bar. Deliver the full heat-map — the shape of the surface is the real result.

RM-A2 · Delta-targeted strikes P1 · Effort S

Hypothesis Fixed 2% OTM is a drifting delta (~0.10 calm → ~0.35 stress); constant delta stabilizes credit and win rate.
Sweep use_delta_selection: true, target_delta ∈ {0.10, 0.15, 0.20, 0.25, 0.30} on the 2–3 best RM-A1 cells.
Success Beats the matching fixed-OTM cell on honest Sharpe in BOTH train and test at fill count ±20%.

Axis B — Entry pricing realism

RM-B1 · Minimum honest credit-to-width floor P0 · Effort S — run first

Hypothesis Negative expectancy is concentrated in low-credit junk fills; requiring marketable credit ≥ X% of width restores sign on the remainder.
Sweep risk.min_credit_pct ∈ {5 (base), 8, 10, 12, 15, 20, 25}, evaluated against honest credit — on baseline structure and best RM-A1 cell.
Success A threshold with return > 0 and ≥ 150 fills. Report trade-frequency cost per threshold explicitly.

RM-B2 · Entry time-of-day sweep P1 · Effort S

Hypothesis 09:30:02 quotes are opening-rotation/indicative (~2.5× above marketable, per reparam report); 09:35+ entries price real quotes for ~$0.07 (~5%) credit decay.
Sweep Entry slot ∈ {09:30 (base), 09:35, 10:00, 12:00, 15:00} ET.
Success Honest avg credit, fill rate, Sharpe per slot; any slot flipping return positive, or quantitative confirmation of the 09:35 timing fix.

RM-B3 · Stale-mark sanity gate P2 · Effort S

Sweep Reject entry if quoted credit > k × prior-day close mark, k ∈ {1.25, 1.5, 2.0}.
Success Execution hygiene, not edge: unchanged-or-better Sharpe with fewer wasted phantom-priced order slots.

Axis C — Regime / timing filters

RM-C2 · IV-rank / VRP entry gate P1 · Effort M — most theory-sound filter

Hypothesis Sell only when premium is rich, so honest credits are structurally larger relative to width.
Sweep IV-rank ≥ {25, 50, 75} (needs IV-rank series from IronVault chain history); VRP = chain IV − 20d realized ≥ {0, +2, +5} vol pts.
Success Section-1 bar vs ungated baseline. If VRP-gating cannot rescue it, the premium-selling thesis itself is dead at these tenors.

RM-C1 · VIX-level buckets P2 · Effort S  ·  RM-C3 · Term-structure gate P2 · Effort S

Sweep C1: entry only in VIX bucket {<15}, {15–20}, {20–30}, {>30} + cumulative gates ≥ {15, 17, 20}. C3: require VIX/VIX3M ≤ {0.90, 0.95, 1.00} (contango only; signal already wired).
Success Per-bucket honest expectancy. N caveat: 383 honest fills ÷ buckets ⇒ treat sub-100-fill cells as directional only.

RM-C4 · Calendar effects P3 · Effort M

Sweep Day-of-week restriction; skip FOMC/CPI ± 1 trading day (needs events-calendar data).
Success Sharpe delta vs baseline. Severe multiple-comparisons risk — report, never select on, single-slice wins.

Axis D — Risk management

RM-D1 · Profit-target × stop-loss grid P1 · Effort S

Hypothesis At honest $1.34–1.40 credits, SL 1.25× stops out trades the fake $1.63 credits survived; the exit geometry may be what's underwater.
Sweep profit_target ∈ {25, 40, 55, 75}% × stop_loss_multiplier ∈ {1.0, 1.25, 1.5, 2.0} = 16 cells, on baseline + best RM-A1 cell.
Success Sharpe + MaxDD surface. Wider SL mechanically raises win% while fattening the left tail — judge on expectancy and DD, not win%.

RM-D2 · Time-stop / early close P2 · Effort S

Sweep Force-close at DTE ∈ {7, 5, 3, 1} regardless of P&L ("skip gamma week").
Success Section-1 bar; hypothesis is that final-week gamma losses dominate the negative edge.

RM-D3 · Kelly fraction / breaker sweep P3 · Effort S — explicitly last

Warning Sizing cannot flip per-trade edge sign — it only shapes the equity path (no-tiers variant: −79.6% vs −27.1% with breakers).
Sweep Regime fractions {9/7/4, 6/5/3, 4/3/2, 2/2/1} × breakers {on, off} — ONLY on an already sign-positive cell.
Success MaxDD ≤ −15% while retaining ≥ 80% of unsized return.

Axis E — Underlying / diversification

RM-E1 · QQQ / IWM P2 · Effort M

Hypothesis SPY premium at 2% OTM is too thin to cover real spread cost; QQQ's richer IV (and IWM) may clear the hurdle with identical mechanics.
Sweep Baseline + best RM-A1 cells on QQQ (width ≈ $9–10) and IWM (≈ $4–5), keeping width/underlying constant. Validate IronVault 2020–2026 coverage first.
Success Section-1 bar per underlying.

RM-E2 · XSP / SPX P3 · Effort L

Note Improves economics (1256 tax, cash settlement, no assignment) — not edge; the backtest metric won't show the tax benefit. Scoping task on SPX/XSP data availability first; pursue only if a SPY/QQQ cell is already positive.

Axis F — The hard question

RM-F1 · Kill-or-pivot verdict protocol P0 · Effort S (process)

Question Is there ANY parameterization where honest-fill edge is positive AND robust (train + test, plateau, ≥150 fills, slippage-stressed)?
Procedure RM-B1 → RM-A1 → (A2, B2, D1) → (C2 + best combo), one scoreboard, Section-1 bar only. Cap the search: if after axes A–D (~130 runs) zero cells pass, stop.
Decision ≥1 robust pass → promote to a new paper EXP id, 60-day honest-paper confirmation before any live talk.  Wins that fail robustness → curve-fit, treat as no.  Zero passes → KILL EXP-800 (live halt already recommended in reparam §4) and PIVOT: keep the good assets (honest fill model, reprice ladder, fresh-quote guard, Safe Kelly overlay, breakers) and point them at families whose honest baseline is positive. Do not spend further compute making 15-DTE 2%-OTM SPY spreads fill.
